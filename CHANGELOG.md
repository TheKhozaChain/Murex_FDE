# Changelog

This project follows semantic versioning.

## [0.3.0] — 2026-08-04

- Generalised the shared investigation architecture to three executable, persisted scenarios.
- Added `HVB-2829`, which derives a fully explained commodities P&L movement and prohibits unnecessary remediation.
- Added `HVB-2822`, which separates current evidence from history, detects critical ambiguity, and fails closed.
- Added escalation-disposition approval without allowing a failed-closed case to be approved as a confirmed resolution.
- Expanded retrieval, deterministic tools, validation, policy, traces, UI, and the golden evaluation corpus to three cases and twelve measures.
- Retained two scenario previews and the planned 30-case suite as explicitly unmeasured roadmap work.

## [0.2.0] — 2026-08-04

- Converted `HVB-2847` from a client simulation into an executable server-side workflow.
- Added deterministic tools, local retrieval, provider-neutral mock synthesis, citation validation and fail-closed policy.
- Added D1 persistence for runs, evidence, recommendations, approvals, audit events and evaluation results.
- Added one measured golden evaluation case plus unit, integration and adversarial tests.
- Connected investigation, approval, observability and evaluation screens to persisted state.
- Reclassified the 30-case dashboard and four remaining scenarios as roadmap/previews.

## [0.1.0] — 2026-08-04

- Added the HarbourView Bank FDE engagement experience.
- Added five controlled exception-investigation scenarios.
- Added evidence citations, approval decisions, audit events, evaluation, governance, observability, architecture, and ROI views.
- Added project planning, threat model, evaluation, demo, and AI decision-boundary documentation.
